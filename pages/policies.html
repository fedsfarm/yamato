YAMATO / HARDENING

Keep Yamato installed

Force-install Yamato to prevent disabling or removal. Requires administrator access.

Firefox

Run one command, then restart Firefox. If a policy file already exists, merge Yamato’s entry into it.

Linux · terminal

sudo mkdir -p /etc/firefox/policies && printf '%s\n' '{"policies":{"ExtensionSettings":{"root@zeroarch.org":{"installation_mode":"force_installed","install_url":"https://addons.mozilla.org/firefox/downloads/latest/yamato-blocker/latest.xpi"}}}}' | sudo sh -c 'umask 022; set -C; cat > /etc/firefox/policies/policies.json'

Windows · PowerShell as administrator

$p = "$env:ProgramFiles\Mozilla Firefox\distribution"; New-Item -ItemType Directory -Force -Path $p -ErrorAction Stop | Out-Null; New-Item -ItemType File -Path "$p\policies.json" -Value '{"policies":{"ExtensionSettings":{"root@zeroarch.org":{"installation_mode":"force_installed","install_url":"https://addons.mozilla.org/firefox/downloads/latest/yamato-blocker/latest.xpi"}}}}' -ErrorAction Stop

Custom install: adjust $p. Managed Firefox: use Group Policy instead.

Manual setup / macOS

Save as policies.json; merge with existing policies. macOS folder: /Applications/Firefox.app/Contents/Resources/distribution/.

{
  "policies": {
    "ExtensionSettings": {
      "root@zeroarch.org": {
        "installation_mode": "force_installed",
        "install_url": "https://addons.mozilla.org/firefox/downloads/latest/yamato-blocker/latest.xpi"
      }
    }
  }
}

Check: about:policies for errors; about:addons to confirm removal is disabled.

Chrome / Chromium

Linux · terminal

sudo mkdir -p /etc/opt/chrome/policies/managed && printf '%s\n' '{"ExtensionInstallForcelist":["lcjglagcjlajleojohmbcfmjdhbgkadc;https://github.com/fedsfarm/yamato/releases/latest/download/updates.xml"]}' | sudo sh -c 'umask 022; set -C; cat > /etc/opt/chrome/policies/managed/yamato.json'

Chromium: use /etc/chromium/policies/managed. Already using ExtensionInstallForcelist? Append Yamato to that list.

Windows · Command Prompt as administrator

reg add "HKLM\SOFTWARE\Policies\Google\Chrome\ExtensionInstallForcelist" /v 1 /t REG_SZ /d "lcjglagcjlajleojohmbcfmjdhbgkadc;https://github.com/fedsfarm/yamato/releases/latest/download/updates.xml"

Use an unused number for 1. Windows requires AD / Entra ID join or Chrome Enterprise Core enrollment.

macOS · Chrome Enterprise Core setup

1. Set up Chrome Enterprise Core with a business email/domain. It is free; this route needs no MDM subscription.

2. In Google Admin, open Chrome browser → Managed browsers → Enroll and copy the enrollment token.

3. Replace YOUR_TOKEN below, run in Terminal, then fully quit and reopen Chrome. Confirm it appears under Managed browsers.

sudo mkdir -p /Library/Google/Chrome && printf '%s' 'YOUR_TOKEN' | sudo sh -c 'umask 022; set -C; cat > /Library/Google/Chrome/CloudManagementEnrollmentToken'

4. Open Chrome browser → Apps & extensions → Users & browsers. Select the enrolled browser’s organizational unit, click + → Add Chrome app or extension by ID, and enter:

lcjglagcjlajleojohmbcfmjdhbgkadc

Select From a custom URL and enter:

https://github.com/fedsfarm/yamato/releases/latest/download/updates.xml

5. Save, set Installation policy → Force install, and save again. The URL must serve an update manifest pointing to Yamato’s signed CRX.

Enrollment instructions · Extension settings

Check: chrome://policy → Reload policies, then confirm installation in chrome://extensions.

Undo: remove Yamato’s policy entry and restart. Chrome may uninstall it.
